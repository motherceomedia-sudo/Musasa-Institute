# ADRs — Architecture Decision Records

This folder contains Architecture Decision Records (ADRs) for the Musasa Canon. ADRs document important architectural decisions, their context, alternatives considered, and consequences. ADRs are critical to preserve chronology and rationale for the 50+ year archive.

Usage
-----
- Create a new ADR as a numbered Markdown file (e.g., 0001-some-decision.md).
- Use the template in this folder to record the decision.
- Reference ADRs in PR descriptions when the change affects architecture, repository contracts, or engine contracts.

Naming convention
-----------------
NNNN-short-name.md — where NNNN is a zero-padded sequence number.

Status
------
All ADRs are part of the canonical archive and should be authored with the assumption that they will be preserved indefinitely. Use plain language and include links to relevant repository documents and PRs.
